# SMO Map 本地版 —— 超级马里奥 奥德赛 互动收集地图

把 [smo.game-maps.info](https://smo.game-maps.info/) 的互动地图**完整复刻到本地**：
16 张王国地图、1234 个收集点标记、界面与原站一致，**并且进度不会丢**。

---

## 怎么用

1. 双击 **`start.bat`**
2. 浏览器打开 → **http://127.0.0.1:8791/**
3. 用完关掉那个黑色命令行窗口即可

> 首次打开建议在页面里选中保留：地图数据全部在本地，**断网也能用**
> （只有点标记里的 YouTube 视频需要联网）。
>
> 🌏 **语言**：默认**简体中文**，可在「设置 → 语言」切换 繁體中文 / English。

---

## 核心功能

- 16 张王国地图 / 1234 个标记（力量之月、紫币、提示画、检查点等），瓦片全部本地化（5376 张）
- 界面与标记名**全简体中文**（可切繁體 / English）
- **进度保存双保险**：每 2 秒自动写入 localStorage + 手动导出/导入 JSON
- **📖 力量之月获取方法**（点击地图上的月亮标记 → 气泡里显示中文攻略）
  覆盖**全部 16 张地图 / 739 条**（位置象限 + 分步骤操作 + 原站截图链接），
  蘑菇王国那 64 个成就月亮无坐标（见成就清单页）。
  已于 2026-10-05 清理全部译文残留（重复标题行 / 站点套话 / `<youtube>` 占位符 / 无用小标题）。
- **🏆 成就月亮清单**（`achievements.html`，侧边栏「本地增强」可进入）
  蘑菇王国 Toadette 的 64 个成就奖励月亮——这些没有地图坐标（达成条件后回蘑菇王国找 Toadette 领取），
  单独做成勾选清单：按主题分 6 组、带进度条与搜索、记录存本地并支持导出/导入。

| 功能 | 说明 |
|---|---|
| **点击标记 = 已收集** | 侧边栏点标记名，或点地图上的图标，标记变淡表示已收集 |
| **分类过滤** | 点分类标题可整类设为已收集 / 重置 |
| **搜索** | 侧边栏搜索框，多个关键词用 `;` 隔开 |
| **隐藏已收集** | 设置里勾选，已拿到的会从地图上隐藏 |
| **进度导出 / 导入**（右下角）| 把进度存成 JSON 文件，换浏览器、重装、清缓存都能恢复 |
| **自动保存** | 本版每 2 秒自动把进度写进浏览器存储（原站只在关页面时保存，异常退出就会丢）|

### 关于"进度不丢"的双保险

1. **自动保存**：每 2 秒把当前进度写入浏览器 localStorage
2. **导出文件**：右下角"导出进度" → 得到 `smo-progress-日期时间.json`
   → 以后任何情况（换电脑/换浏览器/清理数据）都能用"导入进度"恢复

> 💡 建议玩一段时间就点一次"导出进度"，文件存到网盘更保险。

## 目录结构

```
SMO-Map\
├── start.bat              ← 双击启动（自动找 Python 并起服务）
├── server.py              ← 本地服务：静态文件 + /progress 进度存档端点
├── README.md / NEXT.md    ← 使用说明 / 项目状态与关键约定

└── web\                   ← 网站本体
    ├── index.html         ← 主页（引用已全部本地化）
    ├── css\  js\          ← 样式 + 进度工具
    ├── vendor\            ← Bootstrap / jQuery / AngularJS / Leaflet 等库（本地化）
    ├── ng\                ← 原站前端逻辑 app.js + 页面模板

```

## 常见问题

**Q: 提示端口被占用 / 打开是空白？**
说明服务已经在运行了，直接访问 http://127.0.0.1:8791/ 即可；
要重启就先关掉旧的命令行窗口。

**Q: 换端口？**
`set SMO_PORT=9000` 后再运行 `start.bat`。

**Q: 地图某块显示空白？**
该处瓦片未下载成功（原站缺图或下载时网络抖动）。
重跑 `scripts\download_tiles.py` 会自动补齐缺失部分（已有文件会跳过）。

**Q: 标记编辑（管理员功能）？**
本地版是只读镜像，不支持新增/编辑标记；需要该功能请用原站。
